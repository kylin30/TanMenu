## TanMenu 0.15.1

### 中文

本版修复新版启动器的启动、窗口恢复和应用页面布局问题。

- 修复首次运行时主界面可能被失焦自动隐藏、需要再次运行才出现的问题。
- 修复窗口隐藏后再次显示时底部出现透明条的问题。
- 统一搜索框、提示区域与应用分类面板之间的间距。
- 修复分类面板底部阴影被裁切的问题。

### English

This release fixes startup, window restoration, and Apps-page layout regressions in the redesigned launcher.

- Fixed a cold-start race where auto-hide could conceal the main window until TanMenu was launched again.
- Fixed a transparent strip appearing below the window after it was hidden and shown again.
- Normalized spacing between the search field, notices, and application category panels.
- Fixed clipping of category-panel shadows along the bottom edge.
